# ANOTHER LIFE｜另一個人生

SUPER JUNIOR 主題的繁體中文「撿手機」互動網頁遊戲原型。

## 使用 GitHub Pages 發佈

1. 在 GitHub 建立一個新的 repository（例如 `another-life-suju`）。
2. 將本資料夾內的 `index.html` 與 `README.md` 上傳至 repository 根目錄。
3. 開啟 repository 的 **Settings → Pages**。
4. 在 **Build and deployment** 中選擇 **Deploy from a branch**。
5. Branch 選 `main`、資料夾選 `/(root)`，按 **Save**。
6. 等待 GitHub Pages 部署完成後，從 Pages 頁面提供的網址開啟遊戲。

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可。遊戲進度若使用瀏覽器本機儲存，會保存在目前瀏覽器與裝置中；清除網站資料或更換裝置可能會失去進度。

## 備註

這是靜態 HTML 原型，不需要 Node.js、建置工具或後端服務。角色與劇情為虛構創作，並非對真實人物私生活的描述。
